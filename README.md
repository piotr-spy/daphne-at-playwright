## Playwright research project
This project is a starter framework for various E2E test types, using default [Playwright](https://playwright.dev/) installation as a base.

## Features
- Example spec files for both web and API testing
- Page object model implementation with fixtures
- Visual testing for different device and browser combinations

## Requirements
- https://nodejs.org/en - Node 22.14.0 or higher LTS

## Installation
- Clone the repository
- Make sure you have full read/write rights to the local repository folder
- **npm install**

## Running tests
- Open the **runtests.sh** file to set the test run options
- Copy the file path and run it in terminal
- Open **index.html** reports in **playwright-report** folder to analyse results
